# robot_pma Templates

This directory contains template files that robot_pma uses for consistent deliverable creation.

## Available Templates

### Data Model Template
- `data_model_template.md` - Template for creating PROJECT/dev/data_model.md

### Use Cases Template
- `use_cases_template.md` - Template for creating PROJECT/dev/use_cases.md

### Action List Template
- `actionlist_template.md` - Template for creating PROJECT/dev/actionlist.md

### Design Specification Template
- `design_specification_template.md` - Template for design artifacts

## How to Use

1. Copy the relevant template
2. Fill in the [PLACEHOLDER] sections
3. Adapt to your specific project
4. Store the final artifact in PROJECT/dev/

## Template Best Practices

- Keep templates consistent with ROME standards
- Document all sections thoroughly
- Include examples for clarity
- Update templates as methodology improves

---

**Note**: Templates are maintained for consistency across projects using ROME 4.0.
