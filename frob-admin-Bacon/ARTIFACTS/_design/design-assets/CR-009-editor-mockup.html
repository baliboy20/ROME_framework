One new control

A Blocks / Full HTML toggle. Choosing Blocks keeps today's editor untouched, so nothing you already have changes or needs migrating.

Import does the tedious work

Images are pulled out, uploaded, converted and re-linked automatically — that's what takes the file from 707 KB to 14 KB and makes it render in Outlook.

It tells you what's wrong

Unsupplied merge fields are the one thing that fails silently at send time, so import flags them rather than letting blank gaps reach a customer.

No sanitisation

Per your decision, imported HTML is stored and sent verbatim. The preview pane must be sandboxed so the console itself doesn't execute pasted markup.
