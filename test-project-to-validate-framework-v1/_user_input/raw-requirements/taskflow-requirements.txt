TaskFlow Mini - Simple Task Manager

PROJECT OVERVIEW
We need a simple task management application where users can create and manage their personal to-do tasks. This is the first version - we want to keep it simple and add more features later.

USER STORIES

Registration and Login:
- Users need to sign up with their email address and password
- After signing up, they should be able to log in with the same credentials
- The system should remember who they are so they don't have to log in every time

Task Management:
- Once logged in, users should be able to create a new task
- Each task should have a title (required) and a description (optional)
- Users should see a list of all their tasks
- Users should be able to mark a task as done or not done (like checking off a checkbox)
- Users should be able to delete tasks they no longer need

Admin Features:
- System administrators need to be able to see all tasks from all users
- This is for monitoring and support purposes
- Admins should not be able to edit other users' tasks, just view them

BUSINESS RULES

Task Rules:
- Task titles must be at least 3 characters long
- Task titles cannot be longer than 100 characters
- Users can only see their own tasks in the normal view
- Users cannot see or modify other users' tasks
- When a user deletes a task, it should be permanently removed

Security Rules:
- Passwords must be encrypted and never stored in plain text
- Users must be authenticated to access their tasks
- Each user should have their own secure session
- Only users with the "Admin" role can access the admin view

Performance Requirements:
- The task list should load in less than 2 seconds
- Creating a new task should feel instant (< 1 second)
- The app should work smoothly with at least 100 tasks per user

Platform Requirements:
- The app should work on web browsers (Chrome, Firefox, Safari)
- The app should be mobile-responsive (works on phones and tablets)
- The app should work on both desktop and mobile screen sizes

User Experience:
- The interface should be clean and simple
- Users should get clear feedback when they perform actions
- Error messages should tell users what went wrong and how to fix it
- If a user has no tasks, show a helpful empty state message

FEATURES WE ARE NOT INCLUDING (Yet)
These might be added in future versions, but NOT in version 1:
- Task due dates
- Task priorities (high, medium, low)
- Task categories or tags
- Sharing tasks with other users
- Task reminders or notifications
- Recurring tasks
- Task attachments or file uploads
- Task comments or notes
- Team collaboration features
- Task templates

TECHNICAL CONSTRAINTS
- Must use Parse Server for the backend
- Must use Flutter for the frontend
- Must support user roles: "User" and "Admin"
- Must use secure authentication (JWT or similar)
- Must be deployable to a cloud environment

OPEN QUESTIONS
1. Should task titles be case-sensitive when checking for duplicates?
   - For now: No restriction on duplicate titles (users can have multiple tasks with the same name)

2. Should there be a limit on how many tasks a user can create?
   - For now: No limit (but monitor performance if users create 1000+ tasks)

3. Should deleted tasks be soft-deleted (archived) or hard-deleted (permanently removed)?
   - For now: Hard delete (permanently remove from database)

4. Should the admin view show completed and incomplete tasks, or just incomplete?
   - For now: Show all tasks (both complete and incomplete)

5. How long should user sessions last?
   - For now: 7 days, then require re-login

SUCCESS CRITERIA
- Users can register, log in, and manage their tasks
- All business rules are enforced
- Performance targets are met (< 2s load time)
- Security requirements are met (encrypted passwords, secure sessions)
- UI is responsive and works on mobile and desktop
- Admin users can view all tasks for monitoring
