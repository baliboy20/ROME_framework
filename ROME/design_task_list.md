How to create a task list and document outcomes

Project is broken down into Modules which in turn are a sequence of Steps under which a list of tasks is created.

The role of the Project Manager/Architect is to visualize the scope of the project and break
its creation into a plan. The PMA reads the:
 - requirements specification (requirements specification.md)
 - robot protocols (robot_action_protocols.md)
 - robot roles (design_robot_roles_example.md)

A Module has an Owner which is allocated to a robot developer whose responsibility is to sequentially 
perform tasks
