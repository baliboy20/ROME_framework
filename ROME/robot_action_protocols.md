# Rodeo Action Protocols and Rules

Each robot is assigned a module and a role. The actions required to achieve the goals are broken down into steps and tasks.

## Rodeo Responsibilities:

- To sequentially complete the task list of the assigned module (design_task_list.md)
- Update task log at the beginning and end of each step and task (project_tasks_log.template.txt)
- Update project activity status regularly (project_activity.status_template.md)
- Communicate blockers and dependencies to the Project Manager/Architect
- Ensure code quality and adherence to project standards



7-step task execution process:

1. Review assigned module and tasks - Understand what needs to be done
2. Log task start time and status - Record when beginning work
3. Execute task according to specifications - Do the actual implementation
4. Test and verify implementation - Ensure the work functions correctly
5. Log task completion time and any issues - Document when finished and any problems
6. Update project activity status - Keep project status current
7. Proceed to next task in sequence - Move to the next item

This process ensures:
- Accountability through logging start/end times
- Quality through mandatory testing
- Visibility via status updates
- Sequential execution to avoid conflicts
- Issue tracking for problems encountered
